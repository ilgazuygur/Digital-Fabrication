## About this repository

### What was the goal?
To have one place where my teacher and classmates can see how each of my Digital Fabrication projects was made, as a simple website that works on both computers and phones.

### What did I do?
I planned the pages, created this public repository, built the home page and the projects page with the same menu and design, uploaded my project images, and published the site with GitHub Pages.

### What tools/materials did I use?
GitHub and GitHub Pages for storing and hosting the site, HTML and CSS for the pages, a short JavaScript for the mobile menu, and Claude (an AI assistant) to write and revise the code. No physical materials were used.

### What went wrong?
The first design was too complicated, with animations, textures and example projects. Everything was on one page, and the structure didn't match my Advanced AI Concepts class site.

### What did I change? How did I solve the problem?
I simplified the design, moved the projects to their own page, and rebuilt the home page with the same structure as my AI class site. I also rewrote the documentation so every project answers these six questions.

### What was the result?
A clean two-page site where every project is documented in the same format. Adding a new project only means copying one project section in `projects.html` and filling in the answers.

## Adding a new project

1. Upload the project's images to this repository.
2. In `projects.html`, copy an existing `<article class="project">` section and change its `id`, title and image path.
3. Answer the six questions in the copied section.
4. Commit the changes. GitHub Pages updates the site within a minute or two.
