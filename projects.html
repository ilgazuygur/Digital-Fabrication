Project 1

Building This Website

A class website on GitHub Pages where I document every Digital Fabrication project, with a home page and a separate projects page.

What was the goal?

I needed a place to document my Digital Fabrication projects so that my teacher and classmates can see how each one was made. The goal was a clean, simple website hosted on GitHub Pages, with a home page and a separate projects page, that works on both a computer and a phone.

I also wanted it to follow the same structure as the website I made for my Advanced AI Concepts class, so that both class sites feel consistent.

What did I do?

  1. Planned the structure

    I decided on three pages linked from a menu at the top: Home (index.html), Projects (projects.html) and Documentation (documentation.html), plus a link to my GitHub profile.

  2. Created the repository

    On GitHub, I created a new public repository for the class. All the pages and images of the site are stored in it.

  3. Wrote the code with an AI assistant

    I described each page to Claude, an AI assistant, which wrote the HTML, the CSS and a short JavaScript for the mobile menu. I opened every version in the browser and asked for changes until the design was what I wanted.

  4. Built the home page

    index.html has the menu, a short introduction that starts with "Hello, I'm Ilgaz.", a Quick facts panel with my course, languages, interests, goal and school email, and an On this site panel that links to the other pages.

  5. Built the projects page

    projects.html uses the same menu and styles as the home page. Each project is its own section with a details panel and documentation that answers the same six questions.

  6. Added images

    I uploaded project screenshots to the repository, such as image.png for the rocket, and linked them with relative paths like src="image.png", so they load from the same folder as the page.

  7. Published with GitHub Pages

    In the repository, I opened Settings, then Pages, chose Deploy from a branch, selected the main branch and the / (root) folder, and saved. After about a minute, the site was live at a github.io address.

    GitHub Pages settings: Source = Deploy from a branch, Branch = main, Folder = / (root).

  8. Tested on computer and phone

    I opened the site on my laptop and on my phone, clicked every menu link, and checked that the menu turns into a button on small screens.

What tools and materials did I use?

The project is fully digital, so no physical materials were used.

What went wrong?

1. The first design was too complicated

The first version had an animated laser cutting around the top of the page, a wood texture, project filters and example projects I hadn't made. It looked impressive, but it distracted from the actual content and didn't feel like my own site.

2. Everything was on one page

The home page tried to hold the projects, the tools and the about section at the same time, so it was long and hard to scan.

3. Some details were wrong or unnecessary

It said I was in 11th grade, though I'm in 12th, and it had a link to my personal portfolio and a large photo area that this class site doesn't need.

4. It didn't match my other class website

My Advanced AI Concepts site has a clear structure: a menu, an introduction, quick facts and links to each page. This site used a different structure, so the two looked unrelated.

5. My first project documentation was too short

The rocket documentation listed the steps but not what went wrong or how I fixed it, so nobody could learn from my mistakes or rebuild the model from it.

What did I change, and how did I solve the problem?

1. Simplified the design

I removed the animation, the texture, the filters and the example projects, and switched to a plain layout: one typeface, a light background and simple panels.

2. Split the site into pages

The home page is now only an introduction, and the projects have their own page, linked from the menu.

3. Fixed the details

I corrected my grade to 12th, and removed the portfolio link and the photo area.

4. Used the same structure as my AI site

I rebuilt the home page with the same layout as my Advanced AI Concepts site: menu, introduction, Quick facts and an On this site panel. On phones, the menu collapses into a button the same way.

5. Rewrote the documentation around six questions

Every project now answers the same six questions: the goal, what I did, the tools, what went wrong, what I changed and the result. For the rocket, I added exact dimensions and Onshape settings so the model can be rebuilt from scratch.

What was the result?

The finished site has a home page and a projects page that share the same menu and design, and it follows the same structure as my AI class site. It works on computers and phones, and it switches to dark colors when the device is in dark mode.

Every project is documented in the same six-question format, so adding a new project only means copying one project section and filling in the answers.

Project 2

Multi-Stage Rocket Model

A 255 mm tall rocket with a core stage, an upper stage, four side boosters and an engine nozzle, modeled in Onshape from basic sketches, extrudes and revolves.

What was the goal?

This was my first CAD project in Digital Fabrication. The goal was to learn the basic Onshape workflow by modeling a multi-stage rocket: drawing 2D sketches on the right planes, turning them into 3D parts, and copying repeated parts with a pattern instead of drawing them again.

I also wanted the model to be exactly symmetric, so every part had to be built from dimensions around one center axis rather than placed by eye.

What did I do?

The table lists every part with the sizes used in the steps below. The origin is at the bottom of the core stage, and heights are measured upward from it.

PartShapeSizeHeight range
Core stageCylinderØ40 mm, 100 mm tall0 to 100 mm
TransitionCone sectionØ40 mm to Ø25 mm, 20 mm tall100 to 120 mm
Upper stageCylinderØ25 mm, 70 mm tall120 to 190 mm
Nose coneConeØ25 mm base, 40 mm tall190 to 230 mm
Booster body (×4)CylinderØ15 mm, 90 mm tall0 to 90 mm
Booster cone (×4)ConeØ15 mm base, 25 mm tall90 to 115 mm
Engine nozzleCone sectionØ30 mm to Ø36 mm, 25 mm tall0 to −25 mm

  1. Set up the document

    I created a new Onshape document and set the units to millimeters from the Document menu, under Workspace units.

  2. Core stage

    I selected the Top plane, started a sketch and drew a center point circle on the origin, dimensioned to Ø40 mm. Then I extruded it upward.

    Extrude settings: Solid, New, Blind, 100 mm.

  3. Transition

    On the Front plane, I drew a vertical construction line from the origin to use as the rocket's center axis. Next to it I drew the half-profile of the transition as a closed shape: 20 mm wide at a height of 100 mm, narrowing to 12.5 mm wide at 120 mm, with its inner edge on the axis. I revolved it around the construction line.

    Revolve settings: Solid, New, Full, axis = center construction line.

  4. Upper stage

    I clicked the top face of the transition, started a sketch on it and drew a Ø25 mm circle on the center, then extruded it upward.

    Extrude settings: Solid, New, Blind, 70 mm.

  5. Nose cone

    On the Front plane, I drew a right triangle with its vertical edge on the center axis, from 190 mm up to 230 mm, and a 12.5 mm bottom edge. I revolved it around the axis the same way as the transition.

    Revolve settings: Solid, New, Full, axis = center construction line.

  6. First booster body

    On the Top plane, I drew a Ø15 mm circle with its center on the X axis, dimensioned 27.5 mm from the origin. That distance is the core radius (20 mm) plus the booster radius (7.5 mm), so the booster touches the core exactly. Then I extruded it.

    Extrude settings: Solid, New, Blind, 90 mm.

  7. Booster nose cone

    On the Front plane, I drew a vertical construction line 27.5 mm from the origin, through the center of the booster. I drew a right triangle on that line with a 7.5 mm bottom edge at 90 mm and its tip at 115 mm, and revolved it around the booster's line.

    Revolve settings: Solid, New, Full, axis = booster construction line.

  8. Circular pattern

    To make the other three boosters, I used Circular pattern with both the booster body and the booster cone selected. For the axis, I clicked the cylindrical face of the core, which Onshape uses as the center axis.

    Circular pattern settings: Part pattern, 2 parts selected, axis = core face, 4 instances, Equal spacing, 360°.

  9. Engine nozzle

    On the Front plane, I drew the nozzle's half-profile on the center axis: 15 mm wide at 0 mm, widening to 18 mm at −25 mm, below the core. I revolved it around the center axis.

    Revolve settings: Solid, New, Full, axis = center construction line.

  10. Appearance

    In the Parts list, I right-clicked each part and used Edit appearance. I made the nose cones, the transition and the nozzle orange, and the core, upper stage and booster bodies grey, so each section is easy to tell apart.

What tools and materials did I use?

Onshape, a browser-based CAD program, with a free education account. The project is fully digital, so no physical materials were used. All dimensions are in millimeters.

What went wrong?

1. The first revolve failed

For the transition, I first drew the profile as a closed shape floating next to the center, without any line to rotate around. Onshape showed the Revolve feature in red because there was no axis to select.

2. The booster didn't line up with the core

I placed the first booster circle by eye. Viewed from above, it cut slightly into the core, and the circular pattern would have copied that mistake to all four boosters.

3. The pattern copied boosters without nose cones

In my first circular pattern, I only selected the booster body. The result was three new boosters with flat tops, because the cone was a separate part that wasn't in the selection.

What did I change, and how did I solve the problem?

1. Added a construction line as the axis

I drew a vertical construction line from the origin and moved the profile so its inner edge sat on that line. After selecting the line as the axis, the revolve worked. I used the same method for every cone after that.

2. Placed the booster with a dimension

I locked the circle's center to the X axis and dimensioned its distance from the origin as 27.5 mm, the core radius plus the booster radius. Now the booster touches the core exactly, and if I change either diameter later, this is the only other number I need to update.

3. Added the cone to the pattern

I edited the pattern and added the booster cone to the selection, so both parts were copied together. I also learned to finish a part completely before patterning it.

What was the result?

The final model is a 255 mm tall rocket made of 13 parts: the core stage, transition, upper stage, nose cone, engine nozzle, and four boosters with their cones. All four boosters are evenly spaced and touch the core exactly, and the colors make each section easy to identify.

Because every part is built from dimensions around the center axis, the model is easy to change. For example, making the core wider only needs the core diameter and the booster distance to be updated, and the pattern places the boosters again automatically.

Project 3

Rocket Design in Parts

A rocket designed in Onshape as 23 separate parts that slide onto a central rod, including body sections, a fin ring with four fins, a nose cone, a motor mount, an engine nozzle, connector pins and end caps.

What was the goal?

This was my second CAD project in Digital Fabrication. In my first rocket, all the parts were stacked into one finished model. This time the goal was to design the rocket as separate parts that actually fit together, so that each part can be checked, changed and made on its own.

I also wanted every part to be visible at once, so I laid all of them out side by side on one plane instead of stacking them.

What did I do?

The table lists every part, from the top of the rocket to the bottom. Every section has a hole in its center, so all of them slide onto the same rod and stay lined up.

PartShapeColorSize
Nose coneDomeDark greyØ30 mm base, 20 mm tall, Ø10 mm socket underneath
Upper body sectionTapered section with a side slotLight blueØ50 mm to Ø30 mm, 40 mm tall, Ø10 mm hole
Main body sectionCylinderGreyØ56 mm, 60 mm tall, Ø10 mm hole
Coupler ringRingBlueØ50 mm, 10 mm tall, Ø14 mm hole
Fin ringRing with 4 slotsPurpleØ50 mm, 15 mm tall, Ø14 mm hole
Fins (×4)Flat trapezoidPurple40 mm root, 20 mm tip, 25 mm span, 3 mm thick
Motor mountRingGreyØ30 mm, 10 mm tall, Ø10 mm hole
Engine nozzleRingOrangeØ24 mm, 12 mm tall, Ø10 mm hole
Connector pins (×8)CylinderGreyØ9.6 mm, 15 mm long
End caps (×4)DiscPurple, blue, yellow, light blueØ20 mm, 3 mm thick

  1. Planned the parts

    Before opening Onshape, I split the rocket into sections from the nose to the nozzle and decided how they connect: every section has a center hole, and pins join the sections to each other.

  2. Set up the document

    I created a new Onshape document and set the units to millimeters from the Document menu, under Workspace units.

  3. Main body section

    On the Top plane, I drew a Ø56 mm circle on the origin and a Ø10 mm circle inside it for the hole. I selected only the area between the two circles and extruded it, so the hole goes all the way through.

    Extrude settings: Solid, New, Blind, 60 mm.

  4. Upper body section

    On the Front plane, I drew a vertical construction line as the axis. I drew the half-profile 5 mm away from the line, so the revolve leaves a Ø10 mm hole in the center: 20 mm wide at the bottom, narrowing to 10 mm wide at the top, 40 mm tall. After revolving it, I sketched a 6 mm × 15 mm rectangle on its side and used Extrude with Remove to cut the slot.

    Revolve settings: Solid, New, Full, axis = construction line. Slot: Extrude, Remove, Through all.

  5. Coupler ring, motor mount and nozzle

    I made these the same way as the main body: an outer circle and a hole circle on the Top plane, extruded together. Only the diameters and heights change, as listed in the table.

    Extrude settings: Solid, New, Blind, 10 mm (coupler ring and motor mount), 12 mm (nozzle).

  6. Fin ring and fins

    I made the fin ring as a Ø50 mm ring with a Ø14 mm hole, extruded 15 mm. Then I cut four 3 mm wide slots into its side, 90° apart. For the fins, I sketched a trapezoid on the Front plane with a 40 mm root, a 20 mm tip and a 25 mm span, extruded it 3 mm thick, and made four copies.

    Fin extrude settings: Solid, New, Symmetric, 3 mm.

  7. Nose cone

    On the Front plane, I drew a quarter-circle half-profile next to the construction line, 15 mm wide and 20 mm tall, and revolved it, the same method I learned in my first rocket. Then I cut a Ø10 mm socket, 8 mm deep, into its base so it sits on a pin.

    Revolve settings: Solid, New, Full, axis = construction line. Socket: Extrude, Remove, Blind, 8 mm.

  8. Pins and end caps

    I made the connector pins by extruding a Ø9.6 mm circle 15 mm, and the end caps by extruding a Ø20 mm circle 3 mm.

  9. Laid out the parts

    I used Transform with Translate to move every part to its own spot on the same plane, with space between them, so none overlap and each one can be seen clearly.

    Transform settings: Translate by XYZ.

  10. Appearance

    In the Parts list, I right-clicked each part and used Edit appearance to give each section its own color, so it is easy to tell which part belongs where.

What tools and materials did I use?

Onshape, a browser-based CAD program, with a free education account. The project is fully digital, so no physical materials were used. All dimensions are in millimeters.

What went wrong?

1. The pins were the same size as the holes

I first drew the connector pins at Ø10 mm, exactly the same as the holes. On screen they looked like a perfect fit, but with zero space between them, real parts would be too tight to slide together.

2. The fins didn't fit the fin ring

I placed the slots in the fin ring by eye. When I checked from the top view, the slots were not exactly 90° apart, and one fin cut into the ring instead of sitting in its slot.

3. All the parts were stacked on top of each other

Because I drew every part on the origin, they were all created in the same place and overlapped. It was hard to select a single part, and the screenshot showed one messy shape.

What did I change, and how did I solve the problem?

1. Made the pins slightly smaller

I changed the pin diameter to Ø9.6 mm, which leaves 0.2 mm of space on each side. The holes stayed at Ø10 mm, so the pins can now slide in without being loose.

2. Placed the slots with dimensions

I redrew the first slot with dimensions from the center and used the same 3 mm value for both the slot width and the fin thickness. Then I copied the slot around the ring at exactly 90°, so all four fins line up.

3. Moved each part with Transform

I used Transform with Translate to move every part to its own place on the plane. I kept them all on the origin while drawing, so each one was still built around the same center, and only moved them at the end.

What was the result?

The final design is a rocket made of 23 separate parts: the nose cone, two body sections, a coupler ring, a fin ring with four fins, a motor mount, an engine nozzle, eight connector pins and four end caps. Every part is laid out on one plane and has its own color, so the whole rocket can be checked at a glance.

Because every section shares the same center hole and the pins have the right clearance, the parts are designed to fit together for real, not just on screen. This is the biggest difference from my first rocket, where everything was built as one stacked model.
